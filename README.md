# Odin Landing Page

This is a static landing page built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. The main goal of this project is to practice HTML and CSS, specifically focusing on Flexbox layout techniques.


##  Built With
* **HTML5**
* **CSS3** (Flexbox)
* **Git & GitHub** (Version control and GitHub Pages deployment)

## What I Learned
* Structuring an HTML document from a design mockup.
* Using `display: flex` to align items in the header, image grid, and call-to-action sections.
* Managing CSS specificity and resolving class conflicts.
* Deploying a static website using GitHub Pages.
